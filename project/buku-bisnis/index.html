Aplikasi Buku Bisnis

Aplikasi pencatatan keuangan bisnis sederhana — catat pemasukan, pengeluaran, dan lihat ringkasan profit secara otomatis dengan grafik interaktif.

GitHub

Overview

Aplikasi Buku Bisnis adalah solusi pencatatan keuangan yang dirancang untuk pelaku UMKM dan bisnis kecil. Dengan antarmuka yang intuitif, pengguna dapat mencatat setiap transaksi pemasukan dan pengeluaran, lalu melihat ringkasan profit secara otomatis.

Aplikasi ini dibangun dengan Flutter dan menyimpan data secara lokal menggunakan SQLite, sehingga bisa digunakan tanpa koneksi internet. Dilengkapi juga fitur export laporan ke PDF untuk kebutuhan pelaporan.

Challenges & Solutions

Mendesain UI yang simpel namun informatif untuk pengguna non-teknis menjadi tantangan utama. Solusinya adalah menggunakan dashboard visual dengan grafik FL Chart yang menampilkan tren profit bulanan secara intuitif.

Fitur backup & restore data menggunakan file JSON yang bisa disimpan ke cloud storage pengguna, memastikan data tidak hilang saat ganti device.

Key Features

  • Catat pemasukan & pengeluaran
  • Kategori transaksi custom
  • Grafik profit bulanan
  • Export laporan ke PDF
  • Backup & restore data
  • Multi-bisnis dalam satu app
  • Dashboard ringkasan keuangan
