Inventory System

Sistem manajemen inventaris internal perusahaan dengan barcode scanning, laporan stok real-time, notifikasi low stock otomatis, dan integrasi dengan sistem ERP.

Private Project

Overview

Inventory System dibangun sebagai solusi internal untuk sebuah perusahaan distribusi dengan 50+ gudang di seluruh Indonesia. Sistem ini menggantikan proses manual berbasis spreadsheet yang rentan error dan tidak real-time.

Dibangun dengan Laravel Livewire untuk UI yang reactive tanpa JavaScript framework terpisah. Alpine.js digunakan untuk interaksi kecil seperti modal dan dropdown, menjaga bundle size tetap minimal.

Challenges & Solutions

Sinkronisasi data antar gudang yang berbeda timezone menjadi tantangan. Solusinya adalah menyimpan semua timestamp dalam UTC dan melakukan konversi timezone di layer presentation sesuai lokasi gudang.

Integrasi barcode scanner (USB HID) ke browser direalisasikan dengan mendeteksi input "burst" dari scanner yang lebih cepat dari kecepatan mengetik manusia — elegant solution tanpa driver tambahan.

Key Features

  • Barcode scanning terintegrasi (USB HID, tanpa driver)
  • Real-time stock tracking per gudang dan per lokasi rak
  • Notifikasi otomatis saat stok di bawah threshold
  • Transfer stok antar gudang dengan approval workflow
  • Laporan stok dengan grafik tren dan export Excel
  • Audit trail lengkap untuk setiap perubahan stok
  • Role management: Admin, Supervisor, Operator

Tech Stack

Laravel 10 MySQL Livewire 3 Alpine.js Tailwind CSS Redis Chart.js
