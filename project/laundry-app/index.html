Laundry App

Aplikasi mobile laundry management — mulai dari penerimaan order, tracking status cucian, hingga notifikasi pickup untuk pelanggan.

GitHub

Overview

Laundry App adalah aplikasi mobile yang memudahkan pengelolaan bisnis laundry dari hulu ke hilir. Aplikasi ini mencakup penerimaan order, tracking status cucian secara real-time, hingga notifikasi otomatis ketika cucian siap diambil.

Dibangun dengan Flutter untuk performa cross-platform yang optimal, dan Firebase sebagai backend untuk sinkronisasi data real-time antar device.

Challenges & Solutions

Sinkronisasi status order secara real-time antar perangkat kasir dan pelanggan menjadi tantangan utama. Cloud Firestore dengan snapshot listener memastikan setiap perubahan status langsung ter-reflect di semua device.

Implementasi QR code tracking memungkinkan pelanggan mengecek status cucian tanpa perlu membuka aplikasi — cukup scan QR code pada nota yang diberikan.

Key Features

  • Input order dengan estimasi selesai
  • Tracking status cucian real-time
  • Push notification pickup ready
  • History transaksi pelanggan
  • Laporan pendapatan harian
  • Multi-outlet support
  • QR code untuk tracking order

Tech Stack
