Absensi Face Recognition + GPS

Aplikasi absensi karyawan dengan verifikasi face recognition dan validasi lokasi GPS — anti-titip absen dan anti-fake location.

GitHub

Overview

Absensi Face Recognition + GPS adalah aplikasi mobile yang mengkombinasikan teknologi face recognition dan validasi lokasi GPS untuk sistem absensi karyawan yang aman dan akurat. Aplikasi ini dirancang untuk mencegah titip absen dan penggunaan fake GPS.

Menggunakan TensorFlow Lite dan Google ML Kit untuk face recognition on-device, sehingga proses verifikasi wajah berlangsung cepat tanpa memerlukan koneksi internet. Dashboard admin berbasis web (Laravel) menyediakan rekap absensi dan laporan yang komprehensif.

Challenges & Solutions

Liveness detection untuk mencegah penggunaan foto sebagai pengganti wajah asli menjadi tantangan utama. Implementasi menggunakan blink detection dan head movement verification untuk memastikan wajah yang terdeteksi adalah orang yang benar-benar hadir.

Anti-fake GPS menggunakan kombinasi GPS provider checking, mock location detection, dan validasi geofencing radius untuk memastikan karyawan berada di lokasi yang benar saat melakukan absensi.

Key Features

  • Face recognition untuk verifikasi identitas
  • Validasi lokasi GPS dengan geofencing
  • Anti-spoofing (liveness detection)
  • Rekap absensi bulanan
  • Dashboard admin web (Laravel)
  • Notifikasi keterlambatan otomatis
  • Export laporan absensi ke Excel
