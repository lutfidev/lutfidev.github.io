CBT Test Potensi Akademik

Computer Based Test untuk ujian Tes Potensi Akademik — dilengkapi timer otomatis, bank soal, randomisasi soal, dan hasil skor instan.

GitHub Demo

Overview

CBT Test Potensi Akademik adalah platform ujian berbasis komputer yang dirancang untuk menyelenggarakan Tes Potensi Akademik (TPA) secara online. Sistem ini mendukung berbagai kategori soal — verbal, numerik, dan logika — dengan randomisasi otomatis untuk setiap peserta.

Dilengkapi timer countdown per sesi, anti-cheating measures, dan kalkulasi skor instan setelah ujian selesai. Admin dapat mengelola bank soal dan mengekspor hasil ujian ke Excel.

Challenges & Solutions

Anti-cheating implementation menjadi prioritas utama. Sistem mendeteksi tab switching dan memaksa fullscreen mode selama ujian. Jika peserta keluar dari fullscreen lebih dari 3 kali, ujian otomatis di-submit.

Randomisasi soal yang adil memerlukan algoritma yang memastikan setiap peserta mendapat distribusi soal yang seimbang dari setiap kategori, bukan sekadar acak total.

Key Features

  • Timer countdown per sesi ujian
  • Randomisasi soal & opsi jawaban
  • Bank soal dengan kategori (verbal, numerik, logika)
  • Hasil skor instan setelah ujian
  • Dashboard admin kelola soal & peserta
  • Export hasil ke Excel
  • Anti-cheating (fullscreen mode, tab detection)
