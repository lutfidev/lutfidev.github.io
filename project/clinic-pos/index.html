Clinic Web POS Dashboard

Dashboard POS berbasis web untuk klinik kecantikan — kelola transaksi treatment, penjualan produk, dan laporan keuangan harian dalam satu platform.

GitHub Demo Video

Overview

Clinic Web POS Dashboard adalah sistem point-of-sale berbasis web yang dirancang khusus untuk klinik kecantikan. Platform ini mengintegrasikan seluruh proses bisnis klinik — mulai dari pencatatan transaksi treatment, penjualan produk kecantikan, hingga laporan keuangan harian yang komprehensif.

Dibangun dengan Laravel 11 dan Livewire untuk pengalaman real-time tanpa reload halaman, serta dilengkapi integrasi pembayaran QRIS via Midtrans untuk kemudahan pembayaran pelanggan.

Challenges & Solutions

Tantangan utama adalah mengelola concurrent transactions dari beberapa kasir sekaligus tanpa terjadi konflik stok produk. Solusinya menggunakan database locking dan queue-based processing untuk memastikan konsistensi data.

Integrasi thermal printer untuk cetak struk juga menjadi tantangan karena variasi hardware. Digunakan ESC/POS protocol yang kompatibel dengan mayoritas thermal printer di pasaran.

Key Features

  • Transaksi treatment & produk
  • Manajemen stok produk klinik
  • Laporan penjualan harian/bulanan
  • Integrasi pembayaran QRIS via Midtrans
  • Multi-user (admin, kasir, terapis)
  • Dashboard analytics real-time
  • Cetak struk thermal printer
