Online Shop

Platform toko online lengkap dengan payment gateway Midtrans, integrasi ongkir RajaOngkir, dan admin dashboard untuk kelola produk serta pesanan.

GitHub Live Demo

Overview

Online Shop adalah platform e-commerce full-featured yang dibangun untuk memudahkan pelaku bisnis berjualan online. Dilengkapi integrasi payment gateway Midtrans yang mendukung berbagai metode pembayaran (VA, QRIS, e-wallet) dan cek ongkir otomatis via RajaOngkir API.

Admin dashboard yang komprehensif memungkinkan pengelolaan produk, pesanan, dan laporan penjualan dalam satu tempat. Sistem ini menggunakan Redis untuk caching dan session management guna memastikan performa optimal di traffic tinggi.

Challenges & Solutions

Race condition pada checkout flow menjadi tantangan kritis — terutama saat flash sale dengan banyak pembeli simultan. Solusinya menggunakan database-level locking dan queue-based payment processing via Laravel Queue.

Integrasi multi-courier shipping dengan RajaOngkir memerlukan caching strategy yang tepat agar response time tetap cepat tanpa terlalu banyak API call. Implementasi Redis cache dengan TTL 24 jam untuk data ongkir yang jarang berubah.

Key Features

  • Integrasi Midtrans (VA, QRIS, e-wallet)
  • Cek ongkir otomatis via RajaOngkir
  • Keranjang belanja & checkout flow
  • Tracking pesanan real-time
  • Admin dashboard kelola produk & order
  • Notifikasi email otomatis
  • Wishlist & review produk
