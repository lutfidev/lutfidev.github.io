Overview

Food Delivery adalah platform delivery makanan komprehensif yang terdiri dari 3 aplikasi mobile (User, Resto, Driver) dan 1 admin panel web. Setiap aplikasi dirancang untuk peran spesifik — user bisa browse resto dan order makanan, resto bisa kelola menu dan terima pesanan, dan driver bisa terima order dan navigasi pengantaran.

Backend dibangun dengan Laravel 11 dan menggunakan Pusher untuk real-time communication antar semua role. Tracking driver menggunakan Google Maps API dengan update lokasi secara berkala.

Challenges & Solutions

Koordinasi real-time antara 3 role berbeda (user, resto, driver) merupakan tantangan arsitektural terbesar. Solusinya menggunakan event-driven architecture dengan Pusher channels yang terpisah per order, memastikan setiap stakeholder mendapat update yang relevan.

Optimasi route untuk driver menggunakan Google Directions API dengan caching strategy agar tidak terlalu banyak API call. Sistem juga menghitung estimasi waktu sampai berdasarkan jarak dan kondisi rute.

Key Features

  • App User: browse resto, order, tracking driver real-time
  • App Resto: kelola menu, terima/tolak order, laporan penjualan
  • App Driver: terima order, navigasi maps, update status delivery
  • Payment gateway Midtrans
  • Push notification semua role
  • Rating & review resto
  • Admin panel web dashboard
