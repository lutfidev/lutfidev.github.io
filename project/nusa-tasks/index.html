Nusa Tasks: Daily Planner

Planner harian local-first — tugas, habit, catatan, dan sesi fokus dalam satu aplikasi. Tanpa akun, tanpa cloud, tanpa tracking.

GitHub

Overview

Nusa Tasks adalah planner harian yang menyatukan tugas, habit, catatan, dan sesi fokus, tersedia dalam bahasa Indonesia dan Inggris. Seluruh data disimpan lokal di perangkat — tidak ada akun, tidak ada server, dan Auto Backup Android sengaja dimatikan agar data tidak pernah keluar dari HP kecuali pengguna sendiri yang mengekspornya.

Detail lengkap proyek ini akan segera ditambahkan.

Key Features

  • Smart views: Inbox, Today, Upcoming, Overdue, Completed, Archive, Trash
  • Prioritas, kategori, tag, subtugas, template, dan tugas berulang
  • Pengingat tugas dan habit, plus pengingat perencanaan/ulasan harian opsional
  • Kalender bulanan/mingguan dan tampilan agenda
  • Habit tracker, catatan, dan timer sesi fokus
  • Trash yang bisa dipulihkan selama 30 hari
  • Backup JSON berversi dengan preview sebelum restore
  • Widget layar utama dan shortcut launcher (Quick add, Today, Focus)
