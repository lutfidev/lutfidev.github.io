Swimming Ticketing

Sistem ticketing kolam renang dengan QR code e-ticket dan pembayaran online — booking tiket, scan masuk, dan dashboard pengelola.

GitHub Live Demo

Overview

Swimming Ticketing adalah sistem booking dan ticketing online untuk kolam renang yang mengintegrasikan pembayaran digital via Midtrans dan QR code e-ticket untuk validasi masuk. Pengunjung bisa booking tiket online, pilih sesi, bayar digital, dan langsung scan QR code di gerbang masuk.

Dashboard pengelola menyediakan informasi real-time tentang kapasitas kolam, pendapatan harian, dan statistik pengunjung untuk membantu pengambilan keputusan operasional.

Challenges & Solutions

Manajemen kapasitas per sesi menjadi tantangan utama — harus memastikan tidak overselling tiket melebihi kapasitas kolam. Implementasi menggunakan database locking dan real-time capacity counter yang ter-update setiap kali ada booking baru.

Pricing dinamis untuk weekday/weekend memerlukan konfigurasi yang fleksibel. Sistem dibuat agar admin bisa mengatur harga per sesi dan per hari dengan mudah melalui dashboard.

Key Features

  • Booking tiket online dengan pilihan sesi
  • Pembayaran via Midtrans (QRIS, VA, e-wallet)
  • Generate QR code e-ticket
  • Scan QR untuk validasi masuk
  • Dashboard pengelola (kapasitas, pendapatan)
  • Laporan pengunjung harian
  • Pricing dinamis (weekday/weekend)
