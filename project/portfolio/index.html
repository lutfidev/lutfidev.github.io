Portfolio Website

Website portfolio personal yang kamu lihat sekarang — dibangun dengan HTML, CSS, dan vanilla JavaScript tanpa framework, menampilkan desain bento grid dark theme dengan animasi interaktif.

View on GitHub Live Site

Overview

Portfolio ini didesain dengan filosofi "less is more" — fokus pada konten dan typography yang kuat daripada animasi berlebihan. Desain bento grid terinspirasi dari desain produk Apple dan Vercel's new website.

Dibangun tanpa framework atau build tool apapun — pure HTML, CSS, dan vanilla JavaScript. Ini membuktikan bahwa web modern yang performant tidak selalu membutuhkan stack yang besar.

Design Decisions

Color palette dipilih dengan sangat hati-hati: hitam #0a0a0a sebagai background utama (bukan pure black yang terlalu keras di mata), dengan aksen biru elektrik #3b82f6 untuk elemen interaktif.

Typography menggunakan dua font: Space Grotesk untuk heading (geometric, modern, kuat) dan Inter untuk body text (highly legible, friendly). Kombinasi ini menciptakan hierarchy yang jelas.

Key Features

  • Bento grid layout asimetris yang unik dan tidak generik
  • Mouse spotlight effect pada setiap card
  • Scroll animations dengan IntersectionObserver
  • Glassmorphism navbar dengan blur effect
  • Halaman detail project dengan navigasi prev/next
  • Fully responsive dari mobile hingga ultrawide
  • Tidak ada dependency — zero JavaScript bundles
  • Lighthouse score 98+ di semua kategori
